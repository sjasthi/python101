Explore / 01

Values, names, input(), print(), type()

Variables refer to values. Reassignment changes the value associated with a name. Common types are int (12), float (12.5), str ("12"), and bool (True or False).

input() returns a string. Use int() or float() to convert valid numeric text. type() reports a type; it does not convert a value. Invalid conversions can raise ValueError.

print(a, b) separates values with a space and ends with a newline. Customize those with sep and end.

points = "14"
points = int(points) + 2
print(points, type(points), sep=" | ")

The text becomes an integer before addition. Try explaining why "14" + "2" would instead produce "142".

Explore / 02

Calculate in the right order

+ - * / // % ** mean addition, subtraction, multiplication, true division, floor division, remainder, and power. Use ** for powers.

For the expressions here: parentheses → powers → * / // % → + -. Operators within the last two groups run left to right; powers group right to left. For example, 2 ** 3 ** 2 means 2 ** (3 ** 2).

/ on integers produces a float. // rounds down: -7 // 2 is -4. Division, floor division, and remainder by zero raise ZeroDivisionError.

29 = 7 × 4 + 1. Parentheses make the addition happen before multiplication.

Explore / 03

Ask a question about values

== != < <= > >= compare values and produce True or False. A single = assigns a value; == tests equality.

Inclusive comparisons (<= and >=) include the boundary. Strings are case-sensitive. 6 == 6.0 is True, but "6" == 6 is False.

A chain such as 5 <= x < 10 requires both comparisons to hold. Ordering incompatible types, such as "6" < 7, raises TypeError.

Explore / 04

Choose which block runs

Start with if, add zero or more elif branches, then an optional final else. Each header ends with a colon. Align the headers and indent their bodies consistently, usually four spaces.

Only the first matching branch of one chain runs. An else has no condition. Separate if statements make separate decisions. Code after the chain continues normally.

Explore / 05

Evaluate only what is needed

and evaluates the left operand first. If it is falsy, the right operand is skipped. or evaluates the left operand first. If it is truthy, the right operand is skipped.

Use a guard before a risky expression: n != 0 and 12 / n > 3. Reversing the order removes that protection. not negates truthiness; it does not combine two operands.

Zero, empty strings, and False are falsy. Nonzero numbers and nonempty strings are truthy. and returns the first falsy operand or the last operand; or returns the first truthy operand or the last operand. They do not always return bool values.

What is Python?

Welcome to your very first class! Let's meet the programming language we'll use all year.

🗣️ It's a language

Python is a way to give instructions to a computer, just like English is a way to talk to a person — except the computer needs very exact instructions.

😀 It's beginner-friendly

Python reads almost like plain English, which is why it's one of the most popular first languages to learn — for kids and professionals alike!

🌍 It's everywhere

Python powers apps like Instagram and Spotify, helps scientists analyze data, and is used to build AI like ChatGPT.

Here is your very first line of Python code:

print("Hello, World!")

This line tells the computer: "Show the text Hello, World! on the screen." The word print is a command, and the text in quotes is what gets displayed.

📄 .py files

Python code is saved in files that end with .py, for example myfirstprogram.py.

# Comments

Anything after a # symbol is a note for humans — the computer ignores it. Example: # this prints a greeting

Next up: two free tools we'll use to write and run Python — PythonTutor and Google Colab. Click the next tab! ➡️

🔍 Meet PythonTutor.com

PythonTutor is a free website that lets you watch your code run, one step at a time — like an X-ray for your program.

  1. Go to pythontutor.com and choose "Start visualizing your code now."
  2. Pick Python as the language.
  3. Type in a few lines of code (or paste some in).
  4. Click Visualize Execution.
  5. Press Next > to step through your code one line at a time and watch variables appear on the right side of the screen.

👀 See variables change

As each line runs, you can watch values appear and change in real time — great for understanding what's actually happening.

🆓 No install needed

It works right in your web browser. Nothing to download.

🐛 Great for finding bugs

When code doesn't do what you expect, stepping through it slowly often reveals exactly where it went wrong.

Open pythontutor.com ↗

Next up: where we'll actually write and save our Python programs — Google Colab. ➡️

☁️ Meet Google Colab

Google Colab (short for "Colaboratory") is a free tool from Google that lets you write and run Python code directly in your web browser — no installation required.

🌐 Runs in the browser

No software to install. If you can open a web page, you can run Python.

💾 Saves to Google Drive

Your Colab notebooks (files ending in .ipynb) are automatically saved to your Google Drive.

🧩 Cells

Colab notebooks are made of "cells." You type code into a cell and run just that piece of code.

  1. Go to colab.research.google.com and sign in with your Google account.
  2. Click New notebook.
  3. Click inside the first gray box (a "code cell") and type: print("Hello, World!")
  4. Press Shift + Enter (or click the ▶ Play button) to run the cell.
  5. Your output appears right below the cell!

🐍 Python 101: Conditions

If/Elif/Else Statement Structure

How does Python choose what to do?

A condition is an expression that evaluates to True or False. Python checks an if / elif / else chain from top to bottom and runs only the first matching branch.

1. if — start here

Required. Check the first condition.

2. elif — another chance

Optional. Use zero or more. Check only if all earlier conditions were False.

3. else — the fallback

Optional. Use at most one, always last. It has no condition.

Follow the decisions

Example: choose a message based on a student's score.

score = 85

if score >= 90:
    print("Excellent!")
elif score >= 70:
    print("Good job!")
else:
    print("Keep practicing!")

print("Done!")

Try a score

Structure rules to remember

  • Start with one if, then any elif branches, then an optional else.
  • Put a colon : at the end of each branch header. Align if, elif, and else; indent their bodies consistently (usually four spaces).
  • Once a condition is True, run its body and skip the remaining branches, even if another condition would also be True.
  • Without else, no branch runs when all conditions are False. Execution still continues after the chain.
  • Valid forms: if alone; if / else; if / elif; if / elif / else.
  • You can nest a new if inside a branch. Separate if statements each check their own condition; they do not share the one-branch rule.

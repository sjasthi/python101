⌨️ input() — Asking the User

        
input() shows a question, waits for the user to type, and gives back what they typed. When you run a cell here, a pop-up box asks for your answer.

Even if you type digits, they arrive as text (a string)

🔍 type() — What Kind of Data Is This?

        
Every value in Python has a data type. type() tells you which one — it's your detective tool when a program doesn't behave the way you expect.


        

            
🔢 int
42, -5, 0

            
📊 float
3.14, -2.5, 7.0

            
✅ bool
True, False

            
📝 str
"Hello", '42'

        


        
1. The four basic types

        

            
            
<class 'int'> means "this value is an int"

            

        


        
2. Tricky look-alikes

        

            
            
Guess each answer before you run it!

            

        


        
3. Variables can change type

        

            
            
The type belongs to the value stored in the variable right now

            

        


        
4. type() + input() — see the conversion happen

        

            
            
Same digits, different types

            

        


        
5. Checking a type and printing it nicely

        

            
            
type(x) == int answers "is x an int?"

            

        


        
🕵️ Debugging tip: If your math gives a strange answer (like 1212 instead of 24), add print(type(your_variable)). If it says str, you forgot to convert your input!

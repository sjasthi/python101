Random Numbers

random.randint(a, b) chooses an integer from a through b, including both endpoints. Import the random module first. Repeated rolls can match; random does not mean “different every time.”

Use a seed to repeat an experiment
A seed starts a reproducible pseudorandom sequence. Resetting the same seed repeats the sequence for the same Python implementation/version. Set it once before several draws; setting it before every draw restarts the sequence.

While Loops - Break
break exits the nearest enclosing loop. It skips the rest of that iteration and continues with the code after the loop. An if inside the loop decides when to break.

While Loop - Continue
continue skips the rest of the current iteration, then checks the while condition again. Unlike break, it does not exit the loop.

Keep the update reachable
Update before a continue can skip it. Otherwise, a loop can get stuck at the skipped value. The remainder operator % helps identify even or odd numbers.

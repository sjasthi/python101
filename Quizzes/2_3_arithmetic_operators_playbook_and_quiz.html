🪜 Operator Precedence — Who Goes First?

        
What is 2 + 3 * 4? Python doesn't just go left to right — it follows precedence rules, just like math class (PEMDAS). Higher steps on the ladder happen first.


        

            
1️⃣ ( )
Parentheses — always first

            
2️⃣ **
Exponents

            
3️⃣ * / // %
left → right

            
4️⃣ + -
left → right

        


        
🧠 Remember PEMDAS: Parentheses, Exponents, Multiply/Divide, Add/Subtract. In Python, // and % sit on the same step as * and /.


        
1. Multiply before you add

        

            
            
Guess each answer before you run it!

            

        


        
2. Same step? Go left to right

        

            
            
* / // % are on the same step, and so are + and -

            

        


        
3. Exponents beat multiplication

        

            
            
** is higher on the ladder than * and /

            

        


        
4. Two tricky ones

        

            
            
When in doubt, add parentheses!

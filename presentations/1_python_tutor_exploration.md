# Day 1 Lab: Exploring Python with Python Tutor

Welcome to Python 101! 🎉 www.learnandhelp.com

Today we are not learning *how* Python works yet — we are just going to **play** with it and watch it run, step by step, using a cool website called **Python Tutor**.

## How to use Python Tutor

1. Open **https://pythontutor.com/**
2. Click **"Start visualizing your code now"**
3. Copy one of the code snippets below and **paste it** into the big text box
4. Click the **"Visualize Execution"** button
5. Click **"Next >"** again and again to watch each line run, one at a time
6. Try **"Last >>"** to jump straight to the end and see all the output

That's it! Try each snippet below in order. Don't worry about understanding every detail yet — we'll learn all of this soon. Today is just for exploring and having fun. 🚀


## Snippet 5: A Few Boxes Together


## Snippet 6: Doing Some Math


## Snippet 7: More Math with Marks


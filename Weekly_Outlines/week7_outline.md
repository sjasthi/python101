### 1. Data Types, Variables, and Basic Functions

- Integers, floats, strings, and Booleans.
- Assignment and reassignment: track the current value of each variable.
- `input()` returns a string; convert valid numeric input with `int()` or `float()`.
- `type()` identifies a value's type.
- `print()` displays values; review `sep` and `end`.

### 2. Arithmetic Operators

- Review `+`, `-`, `*`, `/`, `//`, `%`, and `**`.
- Apply operator precedence and parentheses.
- Distinguish true division, floor division, and remainder.
- Predict the output of code that updates variables.

### 3. Comparison Operators

- Review `==`, `!=`, `<`, `>`, `<=`, and `>=`.
- Distinguish assignment (`=`) from equality testing (`==`).
- Check boundary values and case-sensitive string comparisons.
- Combine comparisons to check whether a value is within a range.

### 4. Conditions

- Review `if`, `if / else`, and `if / elif / else`.
- Use colons and consistent indentation.
- Explain why only the first matching branch in a chain runs.
- Distinguish a single chain from separate `if` statements.
- Review nested conditions and code that runs after a conditional block.

### 5. Boolean Logic and Short Circuit Evaluation

- Review `and`, `or`, and `not`.
- With `and`, a falsy left operand means the right operand is skipped.
- With `or`, a truthy left operand means the right operand is skipped.
- Explain why a guard must appear before an expression such as division by a potentially zero value.

**Review routine:** Read → predict the result → run the code → explain what happened.
